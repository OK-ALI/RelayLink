Smoke procedures extend the existing `tooling/smoke-native.mjs`, `tooling/smoke-android.mjs` and `tests/ui/` suites. Failed checks must be fixed and rerun. Reports record actual commands, outcomes and limitations under this directory; native screenshots and structured evidence live under `docs/testing/evidence/v2.5/`.

Owner terminology refinement: normal Desktop/Mobile screens use Relay Link, Command Center, This PC and Quick Access. Remove workspace breadcrumbs and phase/progress/developer jargon from normal surfaces; retain diagnostic and progress facts in About. Keep unavailable functions honest. Smoke: scan rendered normal screens for excluded wording, verify Quick Access navigation and disabled actions, recapture native comparisons, then rerun affected browser/native regressions.

Native font-scale regression gate: background the retained app as for OS Settings, change Android font_scale 1 → 1.3 → 1 and return. Body text must resize without duplicate router/linking roots, errors or blocked navigation. Check the merged manifest for fontScale handling, inspect actual body bounds/screenshots and ReactNativeJS error logs, restore the original setting and retest motion/navigation. A large heading's fixed line box is not a reliable scaling indicator.

Keyboard/sheet gate: type a keyword into the secondary section picker with the native keyboard open. The sheet and matching result must remain visible above the keyboard; selecting the result must dismiss the keyboard and open the section. Apply the same keyboard-aware container to component-study inputs. Native caption gate: show only Relay Link in the title, and verify every other Tauri configuration value remains identical to the Phase 0 baseline.

Slider correction gate (2026-11-07): the third-party Android slider allocates a 48 dp wrapper but exposes an approximately 18 dp native SeekBar. Provide a full-row adjustable accessibility target and touch-to-set area while retaining native drag behavior. Verify actual native target bounds ≥48 dp, pointer changes, increment/decrement accessibility semantics, finite bounded values, all-theme browser behavior and the native feedback flow. Do not weaken the target-size test to accept a thin SeekBar.

Repeated-link gate (2026-11-07): open local About, press hardware Back to Home, then open the identical About link again. Both entries must display About and Back must return Home. Explicit local navigation must clear the consumed section parameter without discarding session preferences. Retest native links/back, browser URL clearing and the foundation navigation regressions; no pairing URL parsing or authority is added.

Fresh-install test-harness gate (2026-11-07): the clean CI artifact shows Expo's introduction covering the working Home. Its Continue text is only 45 px high and its Close icon 42 px; automation must resolve their actual containing clickable targets rather than lower visibility thresholds or bypass Home verification. Test the captured XML shapes, keep dismissals bounded and state-based, clear only the dedicated emulator's test-app data to reproduce first install, run the real affected startup flow and repeat the clean-runner Android gate. Product code/security remain unchanged.

Browser focus gate (2026-11-07): a clean Chromium run kept volume at 25 after an early ArrowRight. Verify the web Modal's asynchronous focus restoration: after Mobile Jump closes, require focus to return to its trigger before focusing/pressing the range. Keep the expected one-step increment and bounds unchanged; repeat actual Chromium keyboard flows and the affected suite. Do not replace keyboard input with synthetic value updates or waive the assertion.

Fresh-snapshot reliability gate (2026-11-07): one local OS animation-scale transition returned a transient null UIAutomator root. Retry at most three new dumps for that transport condition, reading XML only after a new success marker; never reuse the old file. Unknown errors, missing states and exhausted retries still fail. Unit-check the no-stale-read behavior and run actual native flows after the correction.
