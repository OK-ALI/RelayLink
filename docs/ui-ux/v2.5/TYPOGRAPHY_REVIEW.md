# Typography review — three systems

These are session-only comparisons in the actual Relay Link interfaces. A remains the default on launch and after End preview. No permanent migration is approved. The same layout and wording are used for each system. Candidate loading is asynchronous and a later selection takes priority over an older request.

| C · Editorial — Fraunces / Source Sans 3 | Warm serif headings against a neutral body. Clearly different and expressive; less suited to highly dense controls and compact status labels.                         | Serif limited to headings, with practical sans-serif controls. Strong character comes with a greater need to review heading wraps at large text sizes. | 453,524 bytes                    |

The payload column is the sum of the selected native TTF files, not runtime RAM or APK size. Preview assets are bundled for offline review and selected systems load on demand. Previously loaded previews may remain cached for the session; End preview changes the selection rather than unloading every font. Desktop candidates load local Latin font subsets on demand. Native loading times and actual Windows font-family observations are in the structured evidence; warm-cache timings are observations on this host, not device-class benchmarks.

All five families carry SIL OFL font licenses; wrapper package notices also apply. Copies of the actual supplied licenses are under `docs/legal/fonts/v2.5/`. IBM reserves Plex and Adobe reserves Source; there is no license grant over Relay Link's own source. No proprietary Apple/Samsung fonts were used.

The [glyph audit](../../testing/evidence/v2.5/font-audit.json) checks actual cmap coverage. Arabic, Devanagari and CJK are absent from the selected fonts, and coverage of Greek/Cyrillic differs by face. Symbol checkmarks/arrows can also fall back. System fallback is required; shaping, localization, right-to-left layouts and comprehensive language coverage are not certified by this review. These gaps are not hidden by the Latin-only comparison.

My recommendation for owner review is B for a functional control application, with A as the continuity option. C is a useful expressive comparison, not an assumed production choice. Owner selection remains pending.

## Review procedure

Open Settings → Appearance, select a typography preview, then inspect Home/Command Center and return to Settings. End preview restores A. A cold restart also restores A; backgrounding the retained app keeps the session preview. Compare status labels, device lists, buttons, headings and number shapes; inspect the separate large-text/zoom captures and known fallback gaps before selecting a production system.
