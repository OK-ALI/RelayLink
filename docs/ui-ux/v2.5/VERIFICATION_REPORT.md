No claim of successful game pausing is made.

The [10-minute sample](../../testing/evidence/v2.5/windows/release-resource-sample.json) preceded the final text-color/caption corrections; its binary hash is recorded. Private bytes are about 4.9% above the historical observation. Working-set aggregation can double-count shared pages and increased substantially. The host/emulator/build context is not a controlled laboratory comparison. These observations do **not** establish a resource PASS or prove an improvement. The [final-binary short diagnostic](../../testing/evidence/v2.5/windows/final-binary-short-sample.json) recorded 62.63 seconds / 12 samples, average private 218.33 MiB, peak 219.83 MiB, average aggregate working set 408.25 MiB and CPU zero at measurement resolution. Its binary SHA-256 is `bb709371244f249efd7a171d4cc758d6c6e8f2230aa0a7dc3356a27df865ab38`. It is not substituted for the 10-minute comparison.

Earlier samples overlapping native capture, and an isolated attempt whose application exited during another test instance, were discarded and repeated. The 10-minute sample had no concurrent Windows Relay Link test instance. CPU can undercount exited children. A [five-second app-descendant GPU counter diagnostic](../../testing/evidence/v2.5/windows/gpu-diagnostic.json) observed zero at available resolution; it is not a GPU benchmark. Open-window data does not test the ≤200 MB tray target, gaming overhead, battery, thermal limits, startup or physical low-end performance.

Windows native motion observations found active animations in Balanced/Enhanced and none in Performance/Reduced, with 0/160/220 ms semantic timings. Short rAF intervals are diagnostics rather than physical display FPS or input latency. Android development/emulator frame and memory observations must likewise not be presented as release-performance acceptance.

The actual Android development/emulator diagnostic rendered 427 frames, with 147 reported janky frames (34.43%); p50 was 34 ms, p95 69 ms and p99 101 ms. After the font comparisons and navigation sequence, meminfo reported PSS 357,299 KiB (348.92 MiB) and RSS 497,040 KiB (485.39 MiB). These are adverse diagnostic observations, not a smoothness PASS. Software graphics, development tooling, screen recording and automation affect this run; no matched release/device baseline was available. Investigate with a profiled release on representative physical hardware before performance acceptance. The native motion clip is silent, approximately 19.33 seconds, 540 × 1200; it demonstrates behavior rather than timing certification.
